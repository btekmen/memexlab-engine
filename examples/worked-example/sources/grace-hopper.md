# Grace Hopper and the Invention of the Information Age

Kurt Beyer's archival biography of Grace Hopper — and a history of the birth of software: the
shift from machine-centric to human-centric computing via compilers and high-level languages.

## Key ideas (paraphrased, for extraction)

- Computers should adapt to humans, not the reverse — the philosophical root of software.
- Abstraction creates scale: compilers turned machine code into human-readable languages, unlocking whole industries.
- Software, not hardware, became the durable source of value.
- Standards beat fragmentation: shared languages and interfaces create ecosystems.
- Innovation is institutional — Hopper won by building coalitions, not as a lone genius.

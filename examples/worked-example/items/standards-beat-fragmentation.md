# Standards beat fragmentation

Technology creates value when widely adopted. Competing proprietary systems slow progress;
shared standards (languages, interfaces, protocols) create ecosystems and economic moats.

## Cited facts

- Hopper pushed common languages and standardization (e.g. COBOL) for portability. Source: [[sources/grace-hopper]].

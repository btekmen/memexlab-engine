# Memex Markdown

## Workflow

1. Choose entity type and slug.
2. Add typed frontmatter.
3. Write a concise summary.
4. Add cited facts with source links.
5. Separate inference from fact.
6. Link related entities with wikilinks.

## Output discipline

- Use `[[slug]]` for internal links.
- Do not invent missing facts.
- Mark uncertain claims explicitly.

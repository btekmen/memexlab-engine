# Memex Frameworks

## Workflow

1. Read the topic/item and the relevant lenses in `frameworks/` (e.g. first-principles, inversion, second-order effects, base rates, incentives).
2. Apply each chosen lens as a structured pass; capture what it surfaces — hidden assumptions, failure modes, downstream effects, the reference class, who benefits.
3. Tag the item with the framework(s) used and the latticework problem(s) it addresses (`problem-1` … `problem-5`).
4. Record new claims, questions, or decisions the lens reveals as memex items, with provenance to the source.
5. Cross-link the item to the lens notes so the reasoning stays inspectable.

## Output discipline

- Name the lens applied; don't smuggle in unstated reasoning.
- A lens produces questions and framings, not invented facts.
- Tag latticework problems consistently (see `frameworks/README.md`).
